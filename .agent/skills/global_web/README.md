# Global Web Skill Notes

These notes guide future work on the Global Life School website.

## Mindset

Build like a school team will actually use this website to earn parent trust. The tone should be warm, clear, and specific. The design should feel professional and human, not like a generated template.

## Project Goal

Create a polished school website that presents Global Life School as academically strong, caring, structured, and safe for both day and boarding students.

## What We Use

- React page components in `src/pages`.
- Global CSS in `src/index.css`.
- Existing color tokens: navy, deep navy, accent blue, soft blue, white, and light background.
- Fraunces for confident school-style headings.
- Work Sans for readable body copy and navigation.
- Local image assets for authentic school presence.

## How We Work

- Read the surrounding section before editing so the page keeps one visual language.
- Prefer real admissions and school-life details over generic words like world-class, innovative, or transformative unless they are supported by context.
- Keep cards, grids, and buttons restrained with consistent spacing and radius.
- Make responsive behavior part of the first edit, not an afterthought.
- On mobile, hero text should stay on top and the image should appear below the copy.
- Preserve the hero image size through tablet breakpoints and let the copy take the squeeze. Reduce text size only if needed for balance, never the image size.
- When the image does stack, ensure the hero section still feels compact and strong; avoid large vertical gaps and overly tall state that makes the page look broken.
- Keep documentation updated when the project's direction or design language changes.

## Current Section Standard

For the home page, each section should answer one parent question:

- Hero: What school is this, and how do I take action?
- Stats: Can I quickly trust it?
- About: What does the school believe?
- Why Choose Us: What will my child experience every day?
- Academics: Which level fits my child?
- CTA: What should I do next?
